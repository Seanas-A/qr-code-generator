Options du QR code

La taille fixe la dimension des images exportées. Plus la correction d'erreur est élevée, plus le code reste lisible s'il est abîmé ou partiellement masqué — mais plus il est dense. Les valeurs par défaut conviennent dans presque tous les cas.

Quatre types de QR codes

Un QR code n'est qu'un texte encodé en carré noir et blanc. Ce qui change d'un usage à l'autre, c'est le format de ce texte : une adresse web s'ouvre dans le navigateur, une configuration Wi-Fi déclenche la connexion, une fiche vCard propose d'ajouter un contact au répertoire. Cet outil produit les quatre : lien, réseau Wi-Fi, texte libre et fiche contact.

Créer un QR code pour un réseau Wi-Fi

Saisissez le nom du réseau (SSID) et sa clé : le téléphone se connecte seul après le scan, sans que personne n'ait à dicter le mot de passe. Trois détails font échouer la plupart des générateurs approximatifs, et sont traités ici :

  • Le WPA3 doit être déclaré comme WPA, jamais comme SAE : les téléphones traitent WPA comme un joker et négocient le protocole réellement proposé par la box, alors que SAE est rejeté par beaucoup de lecteurs.
  • Les caractères spéciaux — point-virgule, deux-points, virgule, guillemet, antislash — délimitent les champs du format et doivent être échappés, sinon la clé transmise est fausse.
  • Un réseau caché exige une mention explicite, sans laquelle le téléphone ne trouvera jamais le réseau.

Fiche contact : les champs reconnus par iOS et Android

La fiche suit le format vCard 3.0, celui que les deux systèmes proposent spontanément d'ajouter au répertoire. Sont pris en charge : nom et prénom, organisation, fonction, téléphone mobile et de bureau distingués, adresse e-mail, autant de liens que nécessaire (site web, profil LinkedIn), adresse postale et note libre.

Quelle taille pour imprimer un QR code

Comptez environ un demi-millimètre par module — un module étant l'un des petits carrés de la grille. Le nombre de modules dépend de la quantité de texte encodé, et il est affiché sous l'aperçu :

  • une adresse web courte donne une grille de 29 × 29 : 3 cm suffisent ;
  • une configuration Wi-Fi tourne autour de 33 × 33, soit 3 à 4 cm ;
  • une fiche contact complète atteint 73 × 73 et demande 5 à 6 cm.

Pour une affiche lue à distance, doublez ces valeurs. Le format SVG est vectoriel : il s'agrandit sans perte, contrairement au PNG.

Questions fréquentes

Ce QR code peut-il expirer ?

Non. Le contenu est encodé directement dans l'image, sans passer par un service de redirection. Aucun compte, aucun serveur intermédiaire, donc rien qui puisse cesser de fonctionner ni devenir payant. C'est la différence avec les QR codes dits « dynamiques », qui pointent vers une URL de suivi et dépendent d'un abonnement.

Mes données sont-elles envoyées quelque part ?

Non. Le calcul se fait entièrement dans votre navigateur. La page charge cinq fichiers au démarrage, puis n'émet plus aucune requête : ni ce que vous saisissez, ni la clé de votre réseau Wi-Fi ne quittent votre appareil.

Peut-on modifier un QR code déjà imprimé ?

Non, le contenu est figé dans le dessin. Si l'adresse est susceptible de changer, faites pointer le code vers une page que vous maîtrisez et modifiez la redirection de votre côté.

PNG ou SVG ?

Le SVG pour tout ce qui sera imprimé ou agrandi, puisqu'il reste net à n'importe quelle taille. Le PNG pour un écran, un e-mail ou une messagerie, où il est reconnu partout.

Faut-il une connexion internet ?

Seulement pour charger la page la première fois. Vous pouvez aussi télécharger la version hors ligne : un fichier unique qui fonctionne par simple double-clic, sans réseau, et que vous pouvez transmettre ou archiver.

Combien de texte tient dans un QR code ?

La limite théorique est de 2 953 octets, mais un code aussi rempli devient très dense et difficile à scanner. En pratique, restez sous quelques centaines de caractères pour un scan confortable.

Mon QR code ne se scanne pas, pourquoi ?

Presque toujours parce qu'il est trop petit pour sa densité. Réduisez le texte encodé, imprimez plus grand, ou baissez le niveau de correction d'erreur dans les options — un niveau élevé protège mieux un code abîmé, mais ajoute des modules. Conservez également la marge blanche autour du code : elle fait partie de la spécification.
